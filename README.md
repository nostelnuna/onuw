# 3~35인 한밤의 늑대인간 (One Night Ultimate Werewolf) 웹게임

단 한 번의 밤(60초)과 단 한 번의 낮(5분 토론), 그리고 20초간의 동시 투표로 즉시 승패가 결정되는 **초스피드 심리 추리 보드게임 플랫폼**입니다.

## 🌟 직업별 밤 행동 및 정산 순서
1. **예언자 (Seer)**: 다른 사람 1명의 카드를 보거나, 중앙 카드 2장을 훔쳐봅니다.
2. **강도 (Robber)**: 다른 사람 1명의 카드를 훔쳐 내 카드와 맞바꾸고, 바뀐 내 새 직업을 확인합니다.
3. **말썽쟁이 (Troublemaker)**: 다른 두 사람의 카드를 서로 몰래 맞바꿉니다.
4. **주정뱅이 (Drunk)**: 내 카드를 중앙 카드 1장과 무작위로 교환합니다 (자신은 바뀐 카드를 모름).
5. **불면증환자 (Insomniac)**: 밤이 끝날 때 내 카드가 다른 사람에 의해 바뀌었는지 최종 확인합니다.

## 🏆 승리 조건 판정
* **무두장이(Tanner) 사망 시**: **무두장이 단독 승리!** (죽고 싶어 하는 캐릭터)
* **늑대인간이 1명이라도 처형될 시**: **마을 진영(시민/특수직) 승리!**
* **늑대인간이 아무도 처형당하지 않을 시**: **늑대인간 진영(늑대/미니언) 승리!**
* **사냥꾼(Hunter) 처형 시**: 사냥꾼이 지목한 사람도 물귀신처럼 함께 처형됩니다.

## 🚀 GitHub 및 Render.com 배포 방법 (1분)
1. 다운로드받으신 `onuw_server.zip`의 압축을 풉니다.
2. [GitHub.com](https://github.com)에서 새 저장소(예: `onuw-game`)를 만들고 파일들을 업로드합니다.
3. [Render.com](https://render.com)에서 **[New +]** → **[Web Service]**를 눌러 해당 저장소를 연결하고 배포합니다.
4. 방장 관리자 비밀번호는 **`2146`** 입니다. (원클릭 토론 시간 일시정지 및 연장 지원)
